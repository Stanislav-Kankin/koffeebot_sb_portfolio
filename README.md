# 🎯 Алгоритм мэтчинга
- Умный подбор (основной режим)
- Система рассчитывает баллы совпадения между пользователями:

### Критерий	Баллы
```
Один город	+30
Общий интерес	+15 за каждый
Общая цель	+10 за каждую
Разница в возрасте до 5 лет	+20
Разница в возрасте до 10 лет	+10
Заполненный профиль	+10
```
### Пример:
```
Иван (25 лет, Москва, интересы: программирование, спорт)

Мария (28 лет, Москва, интересы: программирование, книги)

Итог: 75 баллов ✅
```
- Принудительный мэтчинг (резервный)
- Создает пары из оставшихся пользователей
- Игнорирует историю предыдущих мэтчей
- Гарантирует, что никто не останется без пары




# 🚀 Установка и запуск
## 1. Клонирование и настройка
```
git clone <repository-url>
cd cofeebot_sb
python -m venv env
source env/bin/activate  # Linux/Mac
# или
env\Scripts\activate     # Windows
```
## 2. Установка зависимостей

```pip install -r requirements.txt```

## 3. Настройка окружения

# Создайте файл .env:

```env
BOT_TOKEN=your_telegram_bot_token_here
ADMIN_IDS=123456789,987654321 # список id администраторов через запятую
```
## 4. Инициализация базы данных

```
python reset_db.py # по желанию - тестовые пользователи
```

## 5. Запуск бота

```python3 main.py```

```

```

# 🗄 Структура базы данных
### Основные таблицы

- users - профили пользователей

- matches - созданные пары и их статусы

- questions - вопросы анкеты

- user_actions - логи действий

- scheduled_matches - запланированные мэтчинги

# ⚙️ Настройка админов

```

```
# 🎪 Процесс знакомства

1. Заполнение профиля → Пользователь отвечает на 9 вопросов

2. Запуск мэтчинга → Админ запускает подбор пар

3. Предложение → Пользователь получает профиль собеседника

4. Принятие → Оба должны принять мэтч

5. Общение → Пользователи получают контакты друг друга

6. Оценка → Через 30 секунд запрос об успешности мэтча

# 🎯 Критерии подбора пар

## Приоритеты системы
```
География - один город = высокий приоритет

Интересы - общие хобби и увлечения

Цели - совпадение ожиданий от знакомства

Возраст - близкая возрастная группа

История - избегание повторных мэтчей
```

# 💡 Советы по использованию

## Для максимальной эффективности:

1. Поощряйте пользователей заполнять профили полностью

2. Запускайте мэтчинг регулярно (1-2 раза в неделю)

3. Используйте ручной мэтчинг для особых случаев

4. Анализируйте статистику для улучшения алгоритма

5. Следите за балансом качества и количества пар

# 🐛 Отладка и решение проблем

## Частые проблемы:
### 1. "Недостаточно пользователей" - нужно минимум 2 активных пользователя

### 2. "Мэтчи не создаются" - проверьте заполненность профилей

### 3."Пользователи не получают уведомления" - проверьте настройки приватности
